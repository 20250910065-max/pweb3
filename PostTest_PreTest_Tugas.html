A. Pre-Test

1. Jelaskan keudukan CSS dalam pemrograman web.

CSS (Cascading Style Sheets) merupakan bahasa yang digunakan untuk mengatur tampilan dan desain halaman web. CSS berfungsi memperindah halaman HTML, seperti mengatur warna, ukuran tulisan, jenis font, jarak, serta tata letak agar halaman web terlihat lebih menarik dan rapi.

2. Berikan masing-masing satu contoh penggunaan css selektor

  • Selektor Tag : Digunakan untuk memilih elemen berdasarkan nama tag HTML.

    p {

    color: pink;

    }

  • Selektor Class: Digunakan untuk memilih elemen berdasarkan nama class.

    • .judul {

    color: pink;

    }

  • Selektor ID: Digunakan untuk memilih elemen berdasarkan ID.

    • #header {

    background-color: pink;

    }
